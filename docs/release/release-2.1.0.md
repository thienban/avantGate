## 📌 Executive Summary

Modern AI copilots and autonomous agents rely on interactive visual workspaces (lateral Canvas, CRM cards, timelines, audit dossiers) alongside linear chat streams. However, frontend teams have historically faced major architectural hurdles:

1. **Parallel Tool Calling Race Conditions**: When an LLM executes multiple tools simultaneously, asynchronous responses arrive out of order, causing state overwrites, UI flickering, and missing records.
2. **Fragile Client-Side Reverse Engineering**: Frontends frequently parse unstructured chat stream parts (`messages[i].parts` or `toolCalls`) with verbose `switch / case` blocks lacking compile-time schema safety.
3. **Rigid Vendor Lock-In**: Existing copilot libraries (e.g. CopilotKit) introduce 40+ transitive npm dependencies (> 250 KB bundle overhead) and impose rigid, opinionated UI components incompatible with custom design systems (shadcn/ui, Tailwind).
4. **Injection & XSS Vulnerabilities**: Untrusted external URLs generated by tools risk XSS exploitation via `javascript:` or protocol-relative (`//evil.com`) redirect vectors.

**AvantGate v2.1.0 introduces the Presentation Plane: an official, headless, zero-dependency submodule (`avantgate/ui` & `avantgate/ui/react`)** that unifies backend AI governance with frontend canvas state management.

## 🌟 Key Highlights of v2.1.0

### 1. ✉️ Canonical Tool Envelope Protocol (`ToolExecutionEnvelope`) ([FEAT-029](../../tickets/FEAT/FEAT-029-avantgate-ui-submodule.md))

The envelope protocol provides a typed contract for agent tools to declare how their client-side projections (`clientDto`) should merge into the application canvas without exposing visual details to the LLM (`llmDto`):

- **Supported Merge Strategies**:
  - `REPLACE`: Completely replaces existing content or switches canvas views.
  - `APPEND_UNIQUE`: Merges new records into an array without duplicates using a specified `dedupeKey`.
  - `UPDATE_ENTITY`: Surgically patches properties of an existing entity in-place without re-rendering unaffected items.
- **Decoupled Visual Intent (`UIIntent`)**:
  - Actions (`HIGHLIGHT`, `SELECT`, `OPEN_MODAL`, `NAVIGATE`) target specific entity IDs, allowing the canvas to react visually (pulsing a card, scrolling to a row) without backend DOM coupling.

```typescript
import { createToolEnvelope } from "avantgate/ui";

const envelope = createToolEnvelope({
  toolId: "search_crm_prospects",
  kind: "prospect_search",
  mergeStrategy: "APPEND_UNIQUE",
  dedupeKey: "id",
  uiIntent: {
    action: "HIGHLIGHT",
    targetId: "prospect_101",
    targetType: "prospect",
  },
  data: {
    totalFound: 1,
    prospects: [{ id: "prospect_101", name: "Acme Corp", stage: "QUALIFIED" }],
  },
});
```

### 2. ⚡ Deterministic Parallel Concurrency Reducer (`createCanvasReducer`)

When LLMs trigger parallel tool calls, responses resolve asynchronously. The Canvas Reducer provides mathematical, algebraic convergence:

- **$O(N)$ Set-Based Deduplication**: Eliminates duplicate entities in linear time without nested iteration loops.
- **In-Place Entity Patching**: Updates targeted records while preserving array ordering and immutability.
- **Anti-Prototype Pollution Guard (`isSafeKey`)**: Blocks malicious payloads containing `__proto__`, `constructor`, or `prototype` keys from polluting JavaScript runtime prototypes.
- **State Integrity**: Normalizes the canvas state shape (`{ content, activeIntent }`) and synchronizes active intents across updates.

```typescript
import { createCanvasReducer } from "avantgate/ui";

const canvasReducer = createCanvasReducer<AppCanvasMap>();

// Concurrently handles parallel tool completion events without race conditions
const nextState = canvasReducer(currentState, incomingEnvelope);
```

### 3. 🏭 End-to-End Typed Application Factory (`defineCanvas`)

Enables client applications to instantiate their entire typed canvas infrastructure in a single line of code, linking the application state map to envelopes and reducers:

```typescript
import { defineCanvas } from "avantgate/ui";

export interface AppCanvasMap {
  prospect_search: {
    totalFound: number;
    prospects: Array<{ id: string; name: string; stage: string }>;
  };
  prospect_dossier: {
    prospectId: string;
    score: number;
  };
}

export const { createEnvelope, canvasReducer } = defineCanvas<AppCanvasMap>();
```

---

### 4. ⚛️ Polymorphic React View Registry (`avantgate/ui/react`)

Provides an instant $O(1)$ dispatch mechanism connecting tool outputs to dedicated application components:

- **Strict Type Checking**: Every `kind` defined in `AppCanvasMap` must map to a component receiving matching typed props (`data`, `context`, `activeIntent`).
- **Defensive Lifecycle**: Gracefully handles `null`, `undefined`, or unregistered kinds by rendering `null` without throwing runtime exceptions.
- **Zero JSX Runtime Lock-In**: Implemented with native `React.createElement` for universal compatibility across bundlers (Next.js App Router, Vite, Remix).

```tsx
import { createViewRegistry } from "avantgate/ui/react";
import { ProspectSearchResultsView, ProspectDossierView } from "@/components/canvas";

export const { CanvasRenderer } = createViewRegistry<AppCanvasMap>({
  prospect_search: ProspectSearchResultsView,
  prospect_dossier: ProspectDossierView,
});

// In your page or sidebar:
export const CopilotSidebar = ({ canvasState, onSendMessage }) => {
  return (
    <aside className="w-96 border-l p-4">
      <CanvasRenderer state={canvasState} context={{ onSendMessage }} />
    </aside>
  );
};
```

### 5. 🛡️ Native Anti-XSS Sanitizer Guard (`isValidSafeUrl`)

Guards external hyperlinks dynamically emitted by AI tools against script injection and phishing vectors:

- **Hostile Scheme Rejection**: Blocks `javascript:`, `data:`, `vbscript:`, and non-web protocols.
- **Protocol-Relative Bypass Protection**: Rejects URLs starting with `//` (e.g. `//evil.com`), preventing browsers from inheriting the active protocol and performing unauthorized external redirections.
- **WHATWG Native Implementation**: Uses standard browser/Node `URL` parsing in 15 lines of pure code, completely eliminating the need for heavy packages like `validator.js` or `DOMPurify`.

```typescript
import { isValidSafeUrl } from "avantgate/ui/react";

isValidSafeUrl("https://prospectai.io");         // ✅ true
isValidSafeUrl("/crm/prospects/42");             // ✅ true
isValidSafeUrl("#details");                      // ✅ true
isValidSafeUrl("javascript:alert(1)");           // ❌ false
isValidSafeUrl("//phishing.attacker.com/login"); // ❌ false
```

## 📦 Package Subpath Exports

AvantGate v2.1.0 introduces modular subpaths in `package.json`:

```json
{
  "exports": {
    ".": {
      "types": "./dist/index.d.ts",
      "import": "./dist/index.mjs",
      "require": "./dist/index.js"
    },
    "./ui": {
      "types": "./dist/ui/index.d.ts",
      "import": "./dist/ui/index.mjs",
      "require": "./dist/ui/index.js"
    },
    "./ui/react": {
      "types": "./dist/ui/react/index.d.ts",
      "import": "./dist/ui/react/index.mjs",
      "require": "./dist/ui/react/index.js"
    }
  }
}
```

- **`avantgate/ui`**: Pure TypeScript headless core (< 2.5 KB minified). Can run in Node.js, Cloudflare Workers, Edge runtimes, or any frontend framework.
- **`avantgate/ui/react`**: Lightweight React bindings. React is declared as an optional peer dependency (`peerDependenciesMeta.optional: true`).
